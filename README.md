# 🌐 Fundamentals of HTML & CSS

This is a beginner-friendly multi-page website project built using **HTML5** and **CSS3**.  
It was created to practice core web development concepts and basic UI structuring.

---

## 🔗 Live Links

- 🌐 Wireframe: https://wireframe.cc/D2swz4  
- 🚀 Live Preview: https://tahmina-official.github.io/Fundamentals-of-HTML-CSS/

---

## 🚀 Features

- Multi-page website:
  - Home
  - Resources
    - Testimonials
    - Comic Book
    - CSS Properties
      - Inline-Block
      - Block
      - Relative
      - Fixed
      - Absolute
      - Flex
  - Wireframe
  - GitHub Profile
- Basic HTML elements (headings, paragraphs, lists, tables)
- Forms with multiple input types
- Images, video embedding, and YouTube integration
- Simple CSS styling and animations
